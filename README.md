💳 Project Title

# Credit_Card_Financial_dashboard_insight

 Description
 
A Power BI dashboard that delivers end-to-end financial insights on credit card usage and customer behavior. The project ingests raw transactional and customer data from CSV files, models it in Power BI, and presents actionable KPIs and trends across two report views — one focused on transactions and one on customers. It helps financial analysts and business stakeholders monitor spending patterns, revenue contribution, customer segments, and card performance in a single interactive interface.

🛠 Tech Stack

DAX
Power Query 
CSV (Flat Files)

✨ Features

Transaction Report View — Tracks total revenue, transaction volume, interest earned, and spend breakdown by card category, chip usage, and expenditure type
Customer Report View — Analyzes customer segments by income group, age group, education level, marital status, and top contributing states
KPI Cards — At-a-glance metrics for Total Revenue, Total Interest, Total Transaction Amount, and Total Transaction Count
Week-over-Week (WoW) Change Tracking — Monitors revenue and transaction fluctuations on a weekly basis
Gender-based Revenue Split — Compares male vs. female contribution to overall revenue
Card Category Analysis — Breaks down performance by card tier (Blue, Silver, Gold, Platinum)
Quarterly Trend Analysis — Revenue and transaction count trends across Q1–Q4
Incremental Data Support — cc_add.csv and cust_add.csv simulate real-world data refresh/append scenarios
PDF Export — Final dashboards exported as PDFs for offline sharing and presentation
